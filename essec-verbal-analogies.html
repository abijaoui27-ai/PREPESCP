Analogies verbales

Le but n’est pas de reconnaître deux mots du même thème, mais de retrouver exactement le même rapport logique entre deux couples de mots.

1. Objectif du chapitre

Dans cette section, on te donne une paire de mots, puis tu dois choisir parmi plusieurs propositions la paire qui fonctionne exactement de la même manière.

Question type

BOXEUR : GANTS

Quelle paire suit la même logique ?

A. nageur : eau
B. écrivain : roman
C. biologiste : microscope
D. arbitre : règle

Réponse : C. Le boxeur utilise les gants comme outil spécifique, et le biologiste utilise le microscope comme outil spécifique.

Le piège : “nageur : eau” appartient au sport, mais l’eau n’est pas un outil utilisé comme les gants.

Ce que tu vas apprendre : formuler la relation exacte entre deux mots, repérer les familles de relations, puis éliminer les réponses seulement proches.
Méthode concours

2. La méthode en 5 réflexes

1. Transformer en phrase

Ex : médecin : hôpital → “le médecin travaille dans un hôpital”.

2. Identifier le sens exact

Lieu ? outil ? fonction ? œuvre ? effet ? contraire ? catégorie ?

3. Respecter l’ordre

“Auteur → œuvre” n’est pas “œuvre → auteur”.

4. Éliminer le même thème

Deux mots du même univers ne suffisent pas.

5. Tester chaque réponse

Remplace les mots dans ta phrase relationnelle.

6. Choisir la relation précise

Si deux réponses marchent vaguement, prends la plus stricte.

Piège majeur : un rapport vague ne suffit jamais.

4. Mini QCM guidés

Avant de lire la correction, essaie de formuler la relation en une phrase.

QCM 1

MITE : VÊTEMENT

A. tailleur : robe
B. trou : réparation
C. calomnie : réputation
D. tissu : couture
Correction
Réponse : C. La mite détériore le vêtement ; la calomnie détériore la réputation. Même relation : élément destructeur → cible.

QCM 2

PRÉFACE : LIVRE

A. prologue : pièce
B. auteur : roman
C. chapitre : page
D. bibliothèque : livre
Correction
Réponse : A. La préface est une partie introductive d’un livre ; le prologue est une partie introductive d’une pièce ou d’un récit.

QCM 3

INSOMNIE : SOMMEIL

A. fatigue : repos
B. anorexie : appétit
C. tristesse : joie
D. maladie : médecin
Correction
Réponse : B. L’insomnie est un trouble qui perturbe le sommeil ; l’anorexie est un trouble qui perturbe l’appétit.

QCM 4

AUTEUR : ROMAN

A. peintre : chevalet
B. compositeur : symphonie
C. lecteur : bibliothèque
D. imprimeur : papier
Correction
Réponse : B. L’auteur crée un roman ; le compositeur crée une symphonie. Relation : créateur → œuvre.

5. Pièges classiques

Le champ lexical

Tout est lié, mais la relation exacte peut être différente.

L’inversion

“Auteur : roman” n’est pas “roman : auteur”.

Le niveau d’abstraction

Mite/vêtement et calomnie/réputation ont la même structure.

La relation trop large

“X va avec Y” n’est jamais suffisant.

À retenir : si tu n’arrives pas à formuler la relation en phrase courte, ne réponds pas encore.
