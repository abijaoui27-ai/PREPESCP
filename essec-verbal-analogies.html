Chapitre 2 — Verbal

Analogies verbales

Objectif : identifier le rapport exact entre deux mots, puis retrouver la paire qui possède le même rapport. Ce chapitre sert de modèle visuel pour les futurs cours et TD.

Cours & méthodes

La clé est de formuler une phrase relationnelle précise : “X est à Y parce que X ... Y”.

Méthode en 3 étapes
  1. Formuler la relation entre les deux mots en une phrase courte.
  2. Identifier le type exact de rapport : outil, matière, contenant, synonyme, cause, résultat, etc.
  3. Vérifier que la réponse garde le même sens et n’inverse pas la relation.
Relations fréquentes

Outil / utilisateur

  • BOXEUR → GANTS
  • BACTÉRIOLOGISTE → MICROSCOPE
  • Le second terme est l’outil caractéristique du premier.
Relations fréquentes

Matière / transformation

  • BOIS → SCULPTER
  • ARGILE → PÉTRIR
  • Le second terme est l’action adaptée à la matière.
Relations fréquentes

Contenant / limite

  • ÉTAT → FRONTIÈRE
  • PROPRIÉTÉ → CLÔTURE
  • Le second terme délimite le premier.
Relations fréquentes

Agent destructeur / cible

  • MITE → VÊTEMENT
  • CALOMNIE → RÉPUTATION
  • Le premier abîme ou détruit le second.
Relations fréquentes

Synonymes proches

  • RÉPUGNANCE → AVERSION
  • APATHIE → PARESSE
  • Attention : il faut garder le même registre.
Pièges ESSEC

Les erreurs classiques

  • Choisir un mot du même thème mais pas du même rapport.
  • Inverser la relation : résultat au lieu de matière.
  • Confondre cause, effet, outil et objectif.
