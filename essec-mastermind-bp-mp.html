1. Objectif du chapitre

Dans un exercice de Mastermind, on cherche un code secret. On dispose de plusieurs propositions, et chaque proposition donne des indices : combien d'elements sont corrects, combien sont bien places, combien sont mal places.

Le but n'est pas de deviner au hasard. Il faut transformer chaque ligne en information utile : un element absent, un element present, une position possible ou une position interdite.

Idee centrale : une ligne seule donne rarement la solution. La reponse se trouve en croisant les lignes.

2. Les bases BP / MP

Ce chapitre n'a pas besoin d'une section “par coeur”. Il faut surtout comprendre le sens exact des indices.

BP = bien place

L'element est dans le code et exactement a cette position.

MP = mal place

L'element est dans le code, mais il n'est pas a cette position.

0 BP / 0 MP

Aucun element de la ligne n'est dans le code. C'est une elimination totale.

1 BP / 0 MP

Un seul element est correct et bien place. Tous les autres elements de la ligne sont absents.

Lecture simpleBP / MP
Proposition : 3 7 9 — Indice : 1 BP / 1 MP

Deux chiffres parmi 3, 7, 9 sont dans le code. L'un est deja a la bonne place. L'autre est dans le code, mais a une autre place. Le troisieme chiffre est absent.

3. Niveau 1 : code a 3 chiffres

Le niveau 1 correspond aux exercices courts : code a 3 chiffres, peu de lignes, et une logique d'elimination assez directe. Ici, la priorite est de trouver les chiffres absents puis de placer les chiffres certains.

Methode niveau 1

1
Chercher une ligne a zero

Si une ligne donne 0 BP / 0 MP, tous ses chiffres sont absents.

2
Utiliser les lignes avec 1 BP / 0 MP

Elles donnent un chiffre bien place et eliminent les autres chiffres de la ligne.

3
Traiter les MP

Un chiffre MP est present, mais il doit changer de position.

4
Verifier la solution

Le code final doit respecter exactement chaque indice.

Exemple corrige ligne par ligne

A1 2 30 BP / 0 MP

Etape 1 — Ligne A

La ligne A donne 0 BP / 0 MP. Donc 1, 2 et 3 sont absents du code.

Etape 2 — Ligne B

La ligne B donne 1 BP / 0 MP : un seul chiffre parmi 4, 5, 6 est dans le code, et il est bien place.

Etape 3 — Ligne C

La ligne C donne 0 BP / 1 MP. Donc un seul chiffre parmi 4, 7, 8 est present, mais pas a cette position. Cela veut dire que 4 ne peut pas etre bien place en position 1.

Etape 4 — Croisement avec la ligne B

Si 4 ne peut pas etre le BP de la ligne B, alors le BP de la ligne B est soit 5 en position 2, soit 6 en position 3.

Etape 5 — Ligne D

La ligne D donne 2 BP / 0 MP avec 9 5 8. On voit que 5 en position 2 est coherent avec la ligne B. Cela fixe une partie du code.

A retenir : au niveau 1, on avance surtout par elimination et par croisement de deux lignes proches.

4. Niveau 2 : code a 4 ou 5 chiffres, systeme de contraintes

Le niveau 2 est different du niveau 1. Ici, il y a plus de chiffres et plus de lignes. On ne peut plus se contenter de lire les lignes une par une : il faut les traiter comme un systeme.

Difference avec le niveau 1 : au niveau 1, une ligne peut souvent debloquer la question. Au niveau 2, chaque ligne ajoute seulement une contrainte. La solution est le code qui respecte toutes les contraintes en meme temps.

Etape 1 — Traduire chaque ligne

On ne cherche pas tout de suite le code. On traduit d'abord chaque ligne en contrainte : combien de chiffres sont presents, combien sont bien places, quelles positions sont interdites.

Etape 2 — Comparer les chiffres communs

Les lignes 1 et 2 ont le chiffre 1 en commun. Les lignes 1 et 3 ont 2 et 4 en commun. Les lignes 2 et 3 ont 7 et 9 en commun. Ce sont ces chiffres communs qui permettent de reduire les possibilites.

Etape 3 — Exploiter les lignes fortes

La ligne 3 est tres forte : 2 BP / 0 MP signifie que deux chiffres sont bien places et que les trois autres sont absents. Donc aucun chiffre de cette ligne ne peut etre seulement mal place.

Etape 4 — Tester une hypothese puis verifier toutes les lignes

Au niveau 2, on accepte parfois de tester une hypothese. Mais elle doit etre verifiee sur les quatre lignes. Si elle contredit une seule ligne, on l'abandonne.

A retenir : le niveau 2 fonctionne comme un systeme. On ne cherche pas une intuition, on cherche le seul code compatible avec toutes les contraintes.

Methode niveau 2

1
Faire un tableau des contraintes

Pour chaque ligne : combien de chiffres presents ? combien de BP ? combien de MP ?

2
Reperer les chiffres communs

Ce sont eux qui permettent de comparer les lignes entre elles.

3
Noter les positions impossibles

Tout MP signifie : ce chiffre existe, mais pas a cette place.

4
Tester peu d'hypotheses

On teste seulement les hypotheses qui respectent deja plusieurs lignes.

5
Verifier ligne par ligne

La solution doit donner exactement les BP et MP annonces dans chaque ligne.

5. Pieges classiques

  • Piege 1 : croire qu'un MP est presque un BP. Non : un MP interdit precisement cette position.
  • Piege 2 : oublier qu'une ligne 1 BP / 0 MP elimine tous les autres elements de la ligne.
  • Piege 3 : raisonner ligne par ligne sans croiser les indices.
  • Piege 4 : garder une hypothese qui contredit une ligne.
  • Piege 5 : oublier de verifier le code final sur toutes les lignes.

6. Strategie de vitesse

  • 0 a 10 secondes : reperer les lignes les plus fortes : zero, BP sans MP, ou beaucoup de BP.
  • 10 a 25 secondes : comparer les lignes qui partagent des chiffres.
  • 25 a 45 secondes : fixer les chiffres certains et noter les positions impossibles.
  • Fin : tester les codes possibles sur toutes les lignes.
Automatisme : eliminer → croiser → placer → interdire → verifier.
