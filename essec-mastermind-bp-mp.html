Chapitre 3 - Logique & Quantitatif

Mastermind BP / MP

Cours et methode pour resoudre les exercices de deduction avec indices bien places, mal places et systemes de contraintes.

1. Objectif du chapitre

Les exercices de type Mastermind demandent de retrouver un code secret a partir de plusieurs propositions et d'indices. Les indices indiquent combien d'elements sont corrects, et parfois s'ils sont bien places ou seulement presents au mauvais endroit.

Ce chapitre apprend a raisonner proprement : ne pas tester au hasard, mais eliminer, croiser les indices et deduire progressivement le code.

Idee centrale : un indice ne se lit jamais seul. Il faut toujours le comparer avec les autres lignes.

2. Comprendre les indices BP / MP

Ici, ce n'est pas une partie par coeur comme dans les chapitres de nombres ou de lettres. Il faut surtout comprendre exactement ce que signifie chaque indice.

Vocabulaire utilise dans les exercices

BP = bien place

L'element est correct et il est a la bonne position.

MP = mal place

L'element est dans le code, mais pas a cette position.

Absent

L'element n'apparait pas dans le code secret.

Code

Suite de chiffres, lettres ou symboles a retrouver.

Lecture rapide des indices

ExempleBP / MP
Code propose : 3 7 9 — Indice : 1 BP, 1 MP

Cela signifie : parmi 3,7,9, deux elements sont dans le code. L'un est a la bonne position, l'autre est present mais ailleurs.

  • 0 BP / 0 MP : aucun element de la ligne n'est dans le code.
  • 2 BP / 0 MP : deux elements sont exacts et bien places.
  • 0 BP / 2 MP : deux elements sont presents, mais tous les deux mal places.
  • 1 BP / 0 MP : un seul element est correct et il est deja a sa bonne place.

3. Methode generale en 6 reflexes

1
Commencer par les lignes a zero

Une ligne 0 BP / 0 MP elimine tous ses elements. C'est l'information la plus rentable.

2
Comparer les lignes proches

Si deux propositions se ressemblent, regarde ce qui change : c'est souvent la cle.

3
Distinguer presence et position

Un MP prouve la presence, mais interdit la position proposee.

4
Fixer les BP certains

Des qu'un element est certain et bien place, garde-le fixe et raisonne autour.

5
Tester les places interdites

Un element mal place doit changer de colonne. Note les positions impossibles.

6
Verifier toutes les lignes

La solution doit respecter chaque indice. Une seule contradiction suffit a rejeter un code.

4. Niveau superieur : raisonner comme avec un systeme

Quand le code a 4 ou 5 positions et plusieurs lignes d'indices, on peut raisonner comme avec un systeme de contraintes. Chaque ligne donne une equation logique : elle dit combien d'elements de cette ligne appartiennent au code et combien sont a la bonne place.

Reflexe important : une ligne ne donne pas forcement la solution directement. Elle ajoute une contrainte. La solution finale est le seul code qui respecte toutes les contraintes en meme temps.

Exemple de code a 5 chiffres

Systeme BP / MPniveau +
Code a trouver : _ _ _ _ _
Ligne 1 : 1 2 3 4 5 → 1 BP / 1 MP
Ligne 2 : 1 6 7 8 9 → 0 BP / 1 MP
Ligne 3 : 0 2 7 4 9 → 2 BP / 0 MP
Ligne 4 : 0 6 3 8 5 → 0 BP / 2 MP

Ici, on ne peut pas resoudre proprement ligne par ligne. Il faut croiser les informations.

Ce qu'on fait :
1. On compare les lignes qui partagent des chiffres.
2. On note les chiffres certainement presents ou absents.
3. On note les positions interdites par les MP.
4. On garde uniquement les codes qui respectent toutes les lignes.

Traduire en contraintes

Contrainte de presence

La ligne indique combien de chiffres appartiennent au code.

Contrainte de position

Les BP fixent une position possible ; les MP interdisent une position.

Contrainte d'exclusion

Une ligne a 0 elimine tous ses chiffres.

Contrainte globale

La solution doit satisfaire toutes les lignes en meme temps.

  • Ne jamais conclure trop vite sur une seule ligne.
  • Un chiffre peut etre present sans etre bien place.
  • Une hypothese doit etre testee sur toutes les lignes.
  • Sur un code a 5 chiffres, le tableau des positions interdites devient tres utile.

5. Les grands types d'exercices

A. Codes avec chiffres

Le code secret est une suite de chiffres, souvent a 3, 4 ou 5 positions.

B. Codes avec lettres

Meme logique, mais avec des lettres. Il faut faire attention aux positions.

C. Codes avec symboles ou couleurs

La logique est identique : un symbole peut etre present, absent, bien place ou mal place.

D. Systemes de plusieurs lignes

C'est le niveau au-dessus : il faut croiser toutes les lignes comme un systeme et eliminer les codes incompatibles.

6. Exemples expliques

Exemple 1ligne zero
Proposition : 1 2 3 — Indice : 0 BP / 0 MP

Conclusion immediate : 1, 2 et 3 ne sont pas dans le code.

C'est une ligne d'elimination totale.
Exemple 2mal place
Proposition : 4 5 6 — Indice : 0 BP / 1 MP

Un seul chiffre parmi 4,5,6 est dans le code, mais il n'est pas a la place proposee.

Il faut garder une presence possible, mais interdire la position.
Exemple 3bien place
Proposition : 7 8 9 — Indice : 1 BP / 0 MP

Un seul chiffre est correct et il est deja bien place. Les deux autres sont absents.

La ligne donne a la fois une confirmation et deux eliminations.

7. Pieges classiques

  • Piege 1 : confondre mal place et absent.
  • Piege 2 : oublier qu'un MP interdit la position observee.
  • Piege 3 : raisonner ligne par ligne sans croiser les indices.
  • Piege 4 : garder trop longtemps une hypothese contradictoire.
  • Piege 5 : ne pas verifier la solution finale sur toutes les lignes.

8. Strategie de vitesse

  • 0 a 10 secondes : chercher les lignes a 0.
  • 10 a 25 secondes : reperer les elements communs entre lignes.
  • 25 a 45 secondes : fixer les BP certains et deplacer les MP.
  • Fin : verifier la solution sur chaque proposition.
Automatisme : eliminer → comparer → placer → verifier. Pour les codes a 5 chiffres : transformer les lignes en contraintes.
